# Receivables Action Analyzer

Zero-cost browser MVP for testing the hypothesis: **Every unpaid invoice gets an action.**

## Run
Open `index.html` in any modern browser. No server, account, API key, or installation is required.

## Included
- CSV paste workflow
- Overdue calculation
- Evidence completeness
- Monitor / Chase / TReDS candidate / Fix evidence / Escalate actions
- Recovery-readiness score
- Outstanding/overdue/TReDS/recovery totals
- Local-only processing

## Deliberately excluded
- Legal advice or ODR filing
- TReDS submission
- WhatsApp/email sending
- Tally/ERP integration
- Bank access
- Paid AI APIs
- Automatic financing decisions

Those belong to later product stages. The purpose of this MVP is to test the core decision layer before building an expensive autonomous system.
